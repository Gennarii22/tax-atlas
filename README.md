# Tax Atlas

Web app statica che confronta aliquote societarie, personali, IVA/GST e ritenute di 133 giurisdizioni, con un controllo qualità dei dati visibile in ogni scheda.

- `parse.py` estrae i dati dalle schede Deloitte International Tax Highlights (i PDF non sono inclusi).
- `build.py` genera `index.html`, un file unico senza dipendenze da installare.

Progetto personale di Gennaro Pancia, realizzato con l'AI. Non affiliato a Deloitte. Dati a solo scopo dimostrativo: non è consulenza fiscale.
